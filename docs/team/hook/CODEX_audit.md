# Codex code audit: findings and status (installments 1-10, 10-12 November)

The owner ran a Codex audit: persistence, startup and shutdown, rest, release switches and the battle/render clocks (installment 1), then combat, FX, loot and the HUD (installment 2). It is unfinished; when it resumes, new IDs continue from SU-064 here. Codex traced the source but never launched Godot, and its one test run aborted (vstest could not reach the testhost in 90 s; set `VSTEST_CONNECTION_TIMEOUT=600`). So every finding is verified against the code before it is fixed, and a wrong one is rejected with the evidence.

Status per ID: `fixed <commit>`, `rejected: <why>` or `deferred: <why>`.

## Rulings (main session, 10 November)

- **A fourth journey is never silent.** With all three slots used, New Journey asks which journey to replace (name, level, day, last played) and confirms. Cancelling keeps every save.
- **Release builds take no dev overrides.** Tuning-file environment variables (`SU_TEETH`, `SU_TELLS`, `SU_BOARDS`, any like them) and raw dev arguments (`--no-open`) work only when `Args.Dev` (debug or perf builds). Tests and the balance harnesses keep them; logic stays engine-free (the host switches them on).
- **Save outcomes reach the player.** "Journey saved" only after the write succeeded; a failed write says so, and a quit whose save failed does not throw the session away without saying so. StoryNight hides Save as ArenaRun does (or says why it can't).
- **Protected loot is never lost at a run's end.** What can't fit goes somewhere the player can reach (the storeroom or an overflow).
- **Statuses ride landed hits only.** A dodged, i-framed, leapt or fully blocked hit (missile or ground pulse) attaches no chill, burn or slow.
- Legacy zone ids in old saves (`"thornhollow"`): migrate to a live zone rather than strand the save (low priority).
