# Survivor Unchained

A persistent, emergent ARPG built on Survivors-style automated combat.
Beta vertical slice, in progress.

```
npm install
npm run dev        # http://localhost:5173
```

Development views: `?dev=sandbox&time=night` (a moonlit test clearing),
`?dev=gallery&pack=characters` (asset gallery).

Art: KayKit character and prop packs by Kay Lousberg (CC0), optimised by
`tools/assets/build.mjs`; vegetation, rocks, terrain and sky are generated
in code.
