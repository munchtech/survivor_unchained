# act_shoot: her action clips, whole body, frame by frame (the `--act` harness, `godot/src/Actors/PlayerView.Act.cs`)

1. New clip: `shoot.sh --clip NAME "<act flags>" [SECONDS=6] [CLOSE=0.45] [regex]`, e.g. `shoot.sh --clip run_warden "--act-at 1 --act-travel 4 --act-repeat 2" 8 0.45`; the four P4 actions by table: `shoot.sh heroic_leap`, `shoot.sh iron_vow_close`, `shoot.sh` (all 8 runs, ~3.3 min each). The caller takes the godot turn once (`tools/turn.py take godot "<what>" --root <this worktree>`); the clip must be in the pack on disk (`tools/anim/p4_pack.sh --review`).
2. Then `python sheets.py --dense NAME [--first S] [--every 2] [--hold-every 6] [--cams play,close]`: rows of 8 tiles at 1:1, cropped round her tracked pelvis, from 3 movie frames before the act to 0.6 s after it; labels = run time, the clip's frame at 60 fps (`f<n>`: the clip's own playhead in the pose shown, the log's `clip=`; the run clock runs one 30 fps frame ahead of it because the one-shot starts a frame after its fire; old logs without `clip=` show `~f<n>` by the run clock), `end+n` after, START / END / CONTACT (her_events.json's contact frames, always in) / the event fired.
3. Outputs in M (`ACT_M`, default `survivorsunchained_inputs/motion_a1/stageB/actions`): `M/<clip>/clips/<cam>/f%08d.png` (30 fps, 1920x1080; file N is the log's `f=N`), `M/<clip>/logs/<cam>.log`, `M/<clip>/<clip>_<cam>_dense_r<k>_1to1.png` and `_half.jpg` (pictures halved, labels full size).
4. Cameras: `play` = the game's play camera, untouched (~81 px/m, tiles 300x300). `close` = `--close-hold Z --act-rigid`: the view rides her root from the act's start, no lag.
5. Zoom table `Z` in shoot.sh (a higher Z is closer; 0.45 = the game's closest, ~236 px/m): heroic_leap 0.31 (~170 px/m, tiles 440x660), bladestorm_loop 0.45 (880x600), iron_vow 0.45 (440x540), shield_charge 0.45 (620x600).
6. Choosing Z for a new clip (logs only, 16 s a run): `CLOSE=<z> NOMOVIE=1 ACT_M=<scratch> shoot.sh --clip NAME "<flags>" 6 0.45 _close`, then `ACT_M=<scratch> python sheets.py --box NAME`; take the closest Z with "out of the image on 0 frames" (her box + 15 cm).
7. Env: `ACT_M` output folder, `NOMOVIE=1` no frames (logs and measures only), `CLOSE=<z>` overrides Z.
8. Act flags: `--act-at S` (start, run s), `--act-travel M` (meters over the clip's travel window), `--act-hold S` (hold the clip's loop), `--act-spin T` (turns a second), `--act-repeat N`, `--act-rigid` (close only), `--act-raw` (the mixer's pose too).
9. Log lines: `act: <clip> at t=.. (pass 1/1, D s long)`, `event <name> hit at t=`, `loop held over run [a, b] s`, `before` / `end` / `after` points and `blend-in` / `blend-back` paths (skeleton cm; world = x1.04), and per rendered frame `act: scr f= t= pelvis= head= foot= box= ppm= by=<who makes the box's left,top,right,bottom> [off=<parentless bone off its rest>:x,y,z cm@px]`.
10. The box covers every bone but the parentless `root` (clips key it away from her: heroic_leap 2.5 m behind) plus each held piece's own box; `sheets.py <clip>` alone still writes the old mp4 + 8-tile sheets.
