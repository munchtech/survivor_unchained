SURVIVOR UNCHAINED - den test build
===================================

Thank you for testing. This build is one place only: the den (the Hollow).

HOW TO START
  1. Unzip the whole folder anywhere (keep the files together).
  2. Double-click SurvivorUnchained.exe.
  You start in the den as the Warden, level 9. When the den ends (its ruler
  down, or you fall), the result page takes you into a fresh den. Armor
  drops in the den over several clears.

KEYS (keyboard and mouse)
  Move ..................... W A S D
  Aim ...................... the mouse (she faces the cursor)
  Skills ................... Left mouse, Right mouse, 1, 2, 3
  Dash ..................... Space (or Left Shift)
  Flare .................... Q
  Draught (heal) ........... R
  Use / pick up ............ E (or F)
  Pack (inventory) ......... I (or Tab)
  Self (character) ......... C
  Arts (skills) ............ K
  Lamps (talents) .......... L
  Map ...................... M
  Pause / settings ......... Esc
  A gamepad works too. Keys can be changed in Settings (Esc).

IF SOMETHING GOES WRONG
  Please tell us what you were doing, and send the log:
  %APPDATA%\Godot\app_userdata\Survivor Unchained\logs\godot.log
  (paste that path into the Explorer address bar).
