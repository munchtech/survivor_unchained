# Every sound id a recipe can ask the bank for (data/content/sounds.json "events"), with the Sfx method it sits in.
# Documentation only, written by hand from src/Audio/Sfx*.cs. Chains are tried in order; the first BANKED id plays
# (an event is banked when every layer's take family exists in art/sound/sounds.json). Anything not banked: the made recipe plays.
# <material> = bone hide flesh rot stone wood (sounds.json "materials"); <school> = physical fire frost storm holy nature shadow arcane.
